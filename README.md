## Repository Introduction

[Hive](https://github.com/apache/hive) is an open-source data warehouse tool from Apache, built on Hadoop, designed to handle large-scale structured data. This product is based on the Huawei Cloud EulerOS 2.0 64-bit system running on Kunpeng servers, offering an out-of-the-box Hive data warehouse.

## Core Features

- **SQL-like Queries**: Supports standard DDL and DML statements, as well as aggregate functions. You can perform data analysis without writing complex MapReduce code.
- **Execution Engines**: Can be configured to use computing frameworks such as MapReduce, Spark, and Tez to improve processing efficiency.
- **Metadata Management**: Stores metadata in a relational database (e.g., MySQL) to speed up the query semantic checking process.

The open-source image product [**Hive Data Warehouse**](https://marketplace.huaweicloud.com/intl/hidden/contents/356a59ea-442e-469f-8264-3a1227d723f9) provided by this project comes pre-installed with Hive version 3.1.3 and its related runtime environment, along with deployment templates. Refer to the usage guide and start your efficient "out-of-the-box" experience now!

> **System Requirements**:
> - CPU: 2 vCPUs or higher
> - RAM: 4GB or more
> - Disk: At least 40GB
